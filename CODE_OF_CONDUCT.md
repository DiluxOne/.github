# Code of Conduct

Every DiluxOne project adopts the **Contributor Covenant 2.1**:
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
(Spanish: <https://www.contributor-covenant.org/es/version/2/1/code_of_conduct/>).

It applies in every project space (issues, pull requests, discussions) and when
someone represents a project in public.

Report unacceptable behaviour privately to **hola@diluxone.com**. Every report is
reviewed promptly and fairly, and the reporter's privacy is respected.
