# Support

- **Using a product** (how do I…?, it does not work for me): its support
  channel. For a WordPress plugin, its forum on wordpress.org, where answers
  stay public for the next person.
- **A bug in the code:** an issue in that repository.
- **A security problem:** see [SECURITY.md](SECURITY.md), never a public issue.
- **Anything else:** hola@diluxone.com · <https://diluxone.com>
